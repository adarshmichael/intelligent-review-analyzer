
# Intelligent Movie Review Analyzer

An NLP and Machine Learning based movie review analysis system.

## Features

- Sentiment classification
- Positive and negative probability
- Emotion detection
- Movie aspect analysis
- Prediction explanation
- Review quality analysis

## Technologies

- Python
- Scikit-learn
- TF-IDF
- Logistic Regression
- Naive Bayes
- Decision Tree
- KNN
- Transformers
- Gradio

## Dataset

IMDb Movie Reviews Dataset containing 50,000 movie reviews.

## Running the Application

```bash
pip install -r requirements.txt
python app.py
